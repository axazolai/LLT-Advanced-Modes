# LLT – Расширенные режимы

[English](README.md) · **Русский**

Плагин для [Lenovo Legion Toolkit](https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit) (форк Team, 2.36.4.0): ноутбук сам
выбирает режим. Вы описываете *профили* — сочетание источника питания, крышки, нагрузки и внешнего монитора, у каждого свои лимиты
мощности, кривая вентиляторов, режим видеокарты, частота панели, зарядка, таймеры простоя, подсветка клавиатуры и автоматизация, — и ноутбук
переключается между ними сам. Небольшой надзиратель держит это в рабочем состоянии, когда падает LLT, не срабатывает планировщик или
обновление идёт не так.

> Собрано и проверено на одной машине: Lenovo Legion Pro 7 16ARX8H (82WS), Windows 11 LTSC. Плагин пишет настройки прошивки через LLT.
> Прочтите [«Безопасность»](#безопасность) до установки на другую модель.

![Страница «Статус»](docs/img/status.png)

## Что добавлено к штатному LLT

В штатном LLT есть режимы питания (Quiet, Balance, Performance, GodMode с пресетами), гибридный режим, частота экрана, управление
батареей и подсветкой, а также список автоматизации: конвейеры с триггерами и шагами. Каждый конвейер независим, а что победит при
нескольких сработавших, решаете вы. Плагин строит над этим слой:

| | Штатный LLT | Расширенные режимы |
|---|---|---|
| Что определяет настройки | То, что выставили последние сработавшие конвейеры | **В каждый момент действует один профиль**, выбранный по четырём условиям: источник питания (сеть / слабый адаптер / батарея), крышка (открыта / закрыта), нагрузка (простой / работа / ИИ / тяжёлая), внешний монитор (подключён / нет). Побеждает самый конкретный подходящий профиль |
| Полный набор значений | Размазан по конвейерам и пресетам | Профиль хранит **все параметры**: мощность и вентиляторы (пресет GodMode или режим прошивки), режим видеокарты, частоту панели (в том числе динамическую 120/60 и настоящий сигнал 60 Гц), проекцию и частоту внешнего дисплея, режим зарядки, питание USB во сне, турбо / EPP / режим питания Windows, четыре таймера простоя, профиль и яркость подсветки клавиатуры |
| Наследование | нет | Профиль наследует то, что не задал, от профилей выше (корень «Всегда»); страница показывает, откуда взято каждое значение |
| Автоматизация | Один общий список | Собственный редактор шагов LLT **внутри каждого профиля**, события «вход» и «выход»; унаследованные конвейеры можно выключать и переставлять |
| Нагрузка | Задаёте сами | Классы по списку программ (тяжёлая > ИИ > работа > простой), задержка и удержание у каждого профиля, чтобы он не дёргался |
| Пресеты GodMode | Один за раз, вручную | Плагин ведёт **пресет на профиль** (`AM · <название профиля>`), записывает заводские кривые и лимиты и проверяет таблицу вентиляторов и значения видеокарты после каждого применения |
| Крышка и сумка | Действие крышки Windows | Пока плагин управляет, действие крышки — «ничего не делать»; **служба-сторож** усыпляет закрытый ноутбук без дисплея примерно через минуту, если плагин молчит, что бы ни упало |
| Простой | Таймеры Windows | Четыре ступени (затемнение, экран, сон, гибернация) на профиль; плееры и запросы пробуждения читаются из запросов питания Windows; переключатель «игнорировать запросы программы» |
| Обновление LLT | Штатное | **Кипер**: проверка совместимости плагина с новым релизом LLT (все ссылки и рефлексия), резервная копия, обновление, сверка настроек, самопроверка и **автоматический откат**. Без вашего слова ничего не меняется |
| Ручные режимы | Быстрые действия | «Автономия», не засыпать, быстрая зарядка, зарядить до полной, принудительная нагрузка, пауза — каждый снимается нужным событием (адаптер, крышка, перезагрузка) |
| Интерфейс | – | Страница внутри LLT, пункты трея, карточка на главной и меню рабочего стола в стиле LLT; английский и русский встроены, **остальные языки — обычными файлами** |

Заводской набор — 24 профиля под этот ноутбук. Возврат к заводским — одной кнопкой.

## Требования

- Windows 11, права администратора для установки.
- [Lenovo Legion Toolkit, форк Team, **2.36.4.0**](https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit/releases/tag/v2.36.4.0)
  (в пакете лежит его установщик, проверяется по закреплённому SHA-256 и подписи издателя).
- PowerShell 7 и .NET 9 Desktop Runtime.
- Ноутбук Lenovo Legion. Заводские значения и диапазоны прошивки сняты для Legion Pro 7 16ARX8H; другим моделям нужны свои значения,
  на них плагин не проверялся.

## Установка

### Из релиза

1. Установите [PowerShell 7](https://aka.ms/powershell) и [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
2. Скачайте `LLT-Advanced-Modes-<версия>.zip` со страницы Releases и распакуйте.
3. Откройте **PowerShell 7 от администратора** в распакованной папке и выполните:

   ```powershell
   pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install-LegionModes.ps1
   ```

   Скрипт ставит LLT 2.36.4.0, только если его нет, затем плагин, кипер (задача планировщика при входе), службу-сторож и меню рабочего
   стола. Он идемпотентен, журнал — `D:\ProgramData\LegionModes\install.log` (или `%ProgramData%\LegionModes`).
4. Откройте LLT. В левом меню появится пункт **Расширенные режимы**.
5. Плагин ставится **выключенным**: управление остаётся у LLT, пока вы не откроете *Расширенные режимы → Управление* и не нажмёте
   **Взять управление**. «Вернуть управление» отдаёт всё обратно.

Удаление: `Uninstall-LegionModes.ps1` из той же папки (настройки и резервные копии остаются).

### Из исходников

```powershell
git clone https://github.com/axazolai/LLT-Advanced-Modes
cd LLT-Advanced-Modes
pwsh -NoProfile -File .\apps\legion-modes\Build-LegionModes.ps1 -Stage
```

Скрипт ставит закреплённый .NET SDK в `_work\dotnet` (система не меняется), скачивает закреплённый установщик LLT и проверяет его хэш,
собирает, запускает тесты и раскладывает пакет в `depot\software\legion-modes\`. Дальше запустите оттуда `Install-LegionModes.ps1`, как выше.

## Языки и переводы

Интерфейс следует языку самого LLT (*Настройки LLT → Язык*) и меняется **без перезапуска**.

- LLT на русском → интерфейс на русском. Любой другой язык LLT → английский, пока вы не добавите перевод.
- Перевод — файл с именем по коду культуры: `de.json`, `fr.json`, `pt-BR.json`. Это плоский JSON-объект, который сопоставляет
  **русский исходный текст** вашему тексту:

  ```json
  {
    "Статус": "Status",
    "Профили": "Profiles",
    "Найдено {0}": "Found {0}"
  }
  ```

  Подстановки `{0}`, `{1}` оставляйте как есть.
- Английский файл `lang\en.json` в пакете — шаблон: скопируйте его (`src/LegionModes.Plugin/lang/en.json` в исходниках), переименуйте
  и переведите значения.
- Положите файл в `%LOCALAPPDATA%\LenovoLegionToolkit\Plugins\Configs\LegionModes\lang\` — эту папку установка и обновления не трогают.
  Собственная папка пакета (`...\Plugins\LegionModes\lang\`) заменяется при каждом обновлении.
- Для языка LLT `de-DE`: основа — `en`, поверх неё `de`, поверх `de-DE`; ваша папка накладывается поверх папки пакета. Нет ключа —
  берётся английский, затем русский исходный текст.
- **Названия профилей** тоже переводятся, без отдельного экрана: введённое название сохраняется под текущим языком интерфейса; у профиля
  без названия на текущем языке показывается английское (у встроенных профилей есть русское и английское). Пресеты GodMode в списке LLT
  подписаны `AM · <название на текущем языке>`.

Приветствуются pull request'ы с новыми языками: добавьте `src/LegionModes.Plugin/lang/<код>.json` (тесты сверяют английский файл с
исходниками).

## Безопасность

- Плагин пишет лимиты мощности, таблицы вентиляторов, значения видеокарты, частоты экрана и настройки питания Windows через LLT.
  Неверные значения делают машину горячей, шумной или нестабильной. Заводские значения сняты для одного ноутбука.
- Сам управление он не берёт: кнопка «Взять управление» — ваша. Падение плагина, LLT или задачи планировщика закрывает сторож
  (закрытый ноутбук без дисплея засыпает и не остаётся включённым в сумке).
- LLT обновляется только по вашему слову, после проверки совместимости, с резервной копией и автоматическим откатом.
- Заводские профили обходятся без андервольтинга. Если профиль задаёт Curve Optimizer всех ядер и машина трижды подряд выключается
  аварийно, плагин записывает 0 в каждый пресет.

Без гарантий. Использование на ваш риск.
